---

## Главная идея за 30 секунд

Платформа сводит **закупщика** и **поставщиков** в один цикл:

```
Заявка → (политика метода) → Тендер/Аукцион/Прямой заказ → Ставки (запечатаны)
   → Вскрытие → Оценка → Награждение → Контракт → Заказ (PO) → Доставка
   → Приёмка → Счёт (3-way match) → Оплата
```

Деньги — только целые копейки (гяпики), ставки зашифрованы до вскрытия,
каждый шаг — в неизменяемом аудит-журнале, данные организаций разделены на уровне БД (RLS).

## Тур за 10 минут (демо-данные уже на местах)

### 1. Войдите закупщиком — `admin@acme.test`

- **Рабочий стол** — KPI: объём закупок, экономия, активные тендеры, задачи
  («что требует решения прямо сейчас»).
- **Заявки** — внутренние потребности компании. Обратите внимание на статусы:
  - *Спецодежда* — DRAFT (черновик, можно редактировать);
  - *Ремонт кровли* — SUBMITTED (ждёт вашего утверждения — нажмите ✔);
  - у утверждённых заявок видны кнопки **RFQ 🔒 / RFP 📄 / RFI ❓ / Аукцион ⚡** —
    так заявка превращается в закупочную процедуру. Заявки до 500 AZN
    политика отправляет в **прямой заказ** без тендера.
- **Тендеры**:
  - *Серверное оборудование* — **завершённый цикл**: ставки вскрыты, оценка
    проставлена, лот награждён (🏆). Внизу — OCDS-экспорт (международный стандарт
    прозрачности).
  - *Офисная мебель* — **идёт сейчас**: одна запечатанная ставка (🔒 суммы скрыты
    до вскрытия — это принципиально), в Q&A вопрос поставщика и ваш ответ.
  - *RFI: складская логистика* — сбор информации без цен.
  - *Аукцион: дизтопливо* — реверс-аукцион в реальном времени.
- **Контракты** — контракт из награждённого тендера + заказы (PO). Заказ
  *серверного оборудования* прошёл весь путь до ACCEPTED. У заказа *хозтоваров*
  (ISSUED) есть кнопка **✎ Изменить** — так делается поправка к заказу.
- **Счета** — счёт поставщика прошёл 3-way match (заказ ↔ приёмка ↔ счёт) и **оплачен**.
- **Каталоги** — прайс-лист Supply One: мгновенный заказ по согласованной цене, без тендера.
- **Бюджеты** — лимиты на год: видно, сколько «съели» утверждённые заявки.
- **Аналитика** — расходы по месяцам, топ поставщиков, экономия на тендерах.
- **Поставщики** — реестр с рейтингом (OTIF/качество/коммуникации).
- **Верификация** — KYC-кейс Baku Metal ждёт документов поставщика.

### 2. Перелогиньтесь поставщиком — `seller@supply-one.test`

- **Рабочий стол** — открытые тендеры, мои ставки, задачи («подать ставку», «выставить счёт»).
- **Открытые тендеры** — *Офисная мебель* (ставка уже подана — SUBMITTED),
  аукцион дизтоплива — можно перебить ставку.
- **Заказы в работе** — конвейер поставки: CONFIRMED → PACKED → SHIPPED → DELIVERED,
  создание отгрузки с трек-номером. На заказе хозтоваров — **жёлтая панель поправки**:
  закупщик просит 40 → 60 пачек. Нажмите ✓ Принять — суммы пересчитаются атомарно.
- **Счета** — выставленные счета и их статусы (MATCHED / PAID).

### 3. Сквозной сценарий руками (5 минут)

1. Закупщик → Заявки → создайте заявку «Ноутбуки, 10 шт × 1500 AZN» → Отправить → Утвердить.
2. На утверждённой заявке нажмите **RFQ 🔒** → откроется тендер → пригласите обоих
   поставщиков → Опубликовать.
3. Поставщиком: Открытые тендеры → ваш тендер → введите цены → 🔒 подать ставку.
   Вернитесь закупщиком: суммы **скрыты** — виден только факт участия.
4. (На демо дедлайн можно не ждать — в проде тендер закрывается по времени сам.)
5. После вскрытия: оценка → награждение → «Сделать контракт» → выпуск заказа → …

## E-mail-уведомления

Каждое событие (новый заказ, смена статуса, поправка, счёт) шлёт письмо активным
пользователям организации-получателя. Без SMTP (демо) письма видны в логе API:
`docker compose -f infra/docker-compose.prod.yml logs api | grep ✉`
