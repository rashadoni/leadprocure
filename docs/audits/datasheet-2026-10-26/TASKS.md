- Тяжёлые E2E/build запускать на GitHub CI или выделенном ephemeral worker, не Contabo. Существующие проверки безопасности сохранить.
- Сохранить команды воспроизведения, версию кода и машинный результат.
- **Готово:** тесты создают/удаляют только свои данные, полный прогон запускается воспроизводимо; недоступные проверки явно NOT RUN.
- **Зависимости:** нет. Подготовку кода исправлений можно вести до готовности среды, закрывать задачи — после соответствующих проверок.

## LP-A08 · P1 · Обеспечить сопоставимость валют и объёмов — F06
